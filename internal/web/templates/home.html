Un CV est un document, pas une page blanche

Un parser lit des blocs de texte, dans l’ordre. Une colonne, des caractères, rien qui n’aille jamais se perdre sur le côté.

Une seule colonne

L’ordre de lecture suit le flux : rien à deviner.

Du texte, pas des images

DOCX et PDF contiennent des caractères s’extraient, pas des dessins.

Le même ordre partout

Cinq formats partagent le même flux de blocs : le PDF ne réordonne pas ce que le DOCX a écrit.

Rien ne disparaît

Pas de pied de page ni de texte alternatif qui porterait seul une information.

Trois étapes, rien à installer

  1. Décrire

    Un JSON strict : un champ inconnu est rejeté, pas ignoré. L’éditeur web le construit pour vous.

  2. Vérifier

    atscv lint note ce qu’un parser perd, check échoue en CI dès qu’une information se perd.

  3. Exporter

    Un JSON, cinq fichiers : le DOCX pour l’envoi, le PDF pour l’archive, le TEX pour composer, le TXT pour vérifier.

Ce que perd un parser, écrit noir sur blanc

Le linter porte sur ce qui disparaît à l’extraction et ce qui coûte des points dans une recherche par mot-clé — pas sur le style.

$ atscv lint -i data/resume.demo.json
warning dates.start            activities[0]      the period has no start date
        → an undated entry is invisible to a chronological filter

readability 71/100 | ~1 page(s) | 232 words | 4 entries
  • error l’information sera perdue : la commande sort en 1.
  • warning un filtre ou un recruteur perdra un point.
  • info une suggestion, pas un défaut.

La pagination se mesure, elle ne s’espère pas

atscv fait tourner le vrai moteur, avec la vraie police, avant de compter. Les trois règles : un titre ne reste jamais seul en bas de page, une entrée y reste entière, une entrée trop haute se coupe titre et dates ensemble.

$ atscv check -i data/resume.demo.json
ok: 232 words, 4 entries, 10 skills, 1 page
Le détail DOCX

Le .docx applique les mêmes règles avec ce que Word comprend : keepNext sur les titres et le corps de chaque entrée, keepLines sur les titres. Une entrée plus haute qu’une page est coupée là où Word peut, comme le PDF.

L’éditeur, servi par le binaire lui-même

Chez vous, sur votre machine

serve n’écoute que sur le loopback, vos sessions vivent dans le navigateur, le serveur ne garde rien.

Sans compte, sans tiers

htmx est embarqué, la CSP interdit tout script ou style qui sort du serveur. Exception à la demande : le modèle d’analyse IA — le CV, lui, reste dans la page.

Les cinq vues de l’éditeur

Le rendu, le rapport du linter, l’ordre de lecture qu’un parser extrait, la source LaTeX que le téléchargement enregistre — quatre vues du serveur, mises à jour à la frappe — puis l’analyse IA : relecture, réécriture, traduction, par un MiniCPM qui tourne dans le navigateur. Un JSON entre, un JSON sort, cinq formats se téléchargent de la même page.
